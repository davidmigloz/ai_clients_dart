## Public behavior outside the structural diff

- Developer `v1` and `v1beta` both declare `GET /{version}/files/{file}:download`. PR #688 adds the missing `alt=media` parameter to Dart's ordinary Files method and a separate v1beta `generatedFiles.download`. Both use the same binary transfer implementation across IO, web, and stub. Native signed redirects use a credential-free follow-up. [Pinned Python files implementation](https://github.com/googleapis/python-genai/blob/aa813f8bf805b6f4f3e57abb8f04b91d769e23e6/google/genai/files.py#L675) · [Developer Files reference](https://aistudio.google.com/api-reference/files) · [Media download PR](https://github.com/davidmigloz/ai_clients_dart/pull/688)
- #682 covers Vertex Veo model-scoped POST `:fetchPredictOperation` with `operationName`. The generic Dart operations GET stays useful for Developer and other generic operations. The Cloud API returns the completed `response.videos` array and filter fields. [Cloud Veo guidance](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/generate-videos-from-text)
- PR #685 adds typed Vertex v1 and v1beta1 function argument fragments to supported `streamGenerateContent` calls. It keeps the Developer API, unary, and batch wire contracts separate. These fragments are part of Vertex REST streaming. Live asynchronous tool responses use their own protocol. [Cloud function calling guide](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling#streaming_function_call_arguments) · [Arguments PR](https://github.com/davidmigloz/ai_clients_dart/pull/685)
- Core operation changes are accounted for by managed environment list/filter and signed workspace transfers (#662, #673, #674), scoped Genie tokens (#659, #664), and PaLM retirements. The modified forms of the other listed operations are documentation-only. No extra Dart resource should duplicate the `environments:list` or `:get`/ `:delete` discovery aliases.
- #660 adds OAuth registration of Cloud Storage files on the Gemini Developer API. File Search, managed workspace archives, and generated media each have their own resource and download path.
- Other compatibility rows should preserve current public symbols for older tuning and semantic retrieval without claiming active model availability from discovery alone. Google shut down Gemini Developer Veo preview on October 22. The new prediction example uses GA Vertex Veo and the separate Developer video guide points to Omni/Genie.
