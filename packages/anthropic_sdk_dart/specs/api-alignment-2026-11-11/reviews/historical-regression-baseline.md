# Historical transport and model audit

## Evidence and scope

The probes import the exported package APIs and use MockClient or a custom HTTP client with a stalled StreamController. All probes used local fixtures. Anthropic and OpenAI probes used repository commit `65b53e07324c13973fa3045d919630bd79a144af`. OpenAI and open_responses package trees were unchanged at `e47e4eb91517028ab73172d3bd219cbd1ab48a6b`. Anthropic files involved in the shared transport and Managed Agents findings were unchanged at that commit. The later Message Thread and signed compaction additions require integrated review on the final alignment head. The OpenAI package owns its public Responses implementation. The open_responses probe serves as a limited sibling implementation comparison for terminal mapping and diagnostics.

Existing focused Anthropic cancellation and error suites passed 102 tests. Existing OpenAI cancellation, abort and error suites passed 39 tests. The additional probes exercised failures with mocked credentials and response bodies, including invalid UTF-8 bytes and stalled body streams.

The shared HTTP failure and retry fix for [#498](https://github.com/davidmigloz/ai_clients_dart/issues/498) adds deterministic tests in `test/unit/resources/http_error_response_test.dart` and `test/unit/client/retry_after_test.dart`. Buffered, SSE and JSONL handshakes, and direct Files and Skills preserve provider request IDs from a response header or a valid top-level body `request_id`. A header wins when both are present. The exception retains the existing ISO-8601 deadline fallback, and the retry scheduler accepts the bounded numeric and HTTP-date guidance. Streaming HTTP errors honor a declared charset and use tolerant UTF-8 when none is usable.

Malformed successful JSON also reached caller-visible decoder diagnostics. Confirmed paths include Models, Managed Agents, Admin, Compliance, Files, Skills, User Profiles, and native provider requests with credentials applied after the normal interceptor chain. Buffered codecs redact effective credentials in JSON and typed decoder failures, including failed Web casts, while valid application fields round-trip unchanged. Protected work and tunnel decoders suppress malformed response diagnostics that could contain newly issued credentials. Borrowed transports without request metadata retain the actual outgoing request. The transport records observed credentials per response when supplied request metadata omits them. Fixtures cover guarded redirects, metadata isolation, stream ownership, strict UTF-8, raw and encoded echoes, and valid success payloads.

## Sibling comparison

The representative open_responses SSE implementation closes the typed stream and cancels the stalled body once on a malformed known event, while leaving the borrowed transport open. Its unknown response event preserves the nested payload. Its own buffered diagnostics retain the server header for valid errors, but malformed body bytes mask the exception and oversized 429 Retry-After overflows. Its SSE valid 503 loses server response metadata, 429 loses retry guidance, and malformed 503 bytes surface FormatException. These observations apply to the separate open_responses package. The OpenAI public Responses resource uses its own transport.

## Configured timeout

Six buffered and nine streaming/direct fixtures reproduced the unused timeout on the reviewed environments baseline. Dart applies the configured timeout per buffered attempt, after authentication. Streams bound the handshake and raw-byte idle time. A paused subscription suspends the idle clock. A productive stream can continue past one interval. The transport receives an abort signal, and the SDK releases stalled and late borrowed response bodies while retaining the existing retry policy.

The pinned Python SDK uses HTTPX connect, read, write, and pool deadlines. The pinned TypeScript SDK aborts each fetch while waiting for headers. OpenAI Dart already times buffered attempts. The independent Models probe showed that a borrowed stalled response body remains subscribed after its timeout. The packages' different timeout boundaries are recorded for the next cross-client review.

## Opaque path identifiers

Existing Files, Skills, Batches and Managed Agents resource methods included
raw IDs in route templates. A slash split the ID, and a bare dot segment could
normalize to a parent route. The shared path encoder now escapes each opaque
ID once and rejects empty, dot-only, and invalid Unicode identifiers. It also
rejects dot segments before semicolon parameters, which intermediaries may
strip. A caller-supplied percent-encoded dot remains literal text. The Files
and Skills alignment introduced the guard for those resources. The follow-up
applies it across the existing and newly aligned sibling resources.
[Pinned Python path template](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/_utils/_path.py) · [Pinned TypeScript path template](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/internal/utils/path.ts)

The local fixture checks 24 public paths. It covers escaped slash, query and
fragment text, pre-escaped dots, nested identifiers, proxy prefixes, and
repeated base query parameters. Invalid inputs fail before any HTTP send.
The scope includes Files and Skills binary methods, JSONL, Managed Agents,
Admin, Compliance, and workspace MCP tunnels and certificates.

The pinned OpenAI Files and Batches probe reproduces two related gaps.
A slash in `Files.retrieve` becomes a second route component, and
`batches.retrieve('..')` sends to the parent endpoint. OpenAI Admin and Safety
already use guarded encoded identifiers for their own routes.

## Unfamiliar stop reasons

The baseline strict `StopReason` enum rejected new provider values in buffered Messages, SSE deltas, batch items and the exported legacy Completion DTO. The official SDKs declare the known strings but preserve response fields as received. Dart exposes the typed `unknown` value alongside the original `stopReasonValue`, including through streaming accumulation and copies. The cross-client baseline records that OpenAI Chat normalizes an unrecognized finish reason to `unknown` and loses its original text.
