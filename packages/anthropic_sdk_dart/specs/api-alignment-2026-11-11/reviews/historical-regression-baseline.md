# Historical transport and model audit

## Evidence and scope

The probes import the exported package APIs and use MockClient or a custom HTTP client with a stalled StreamController. All probes used local fixtures. Anthropic and OpenAI probes used repository commit `65b53e07324c13973fa3045d919630bd79a144af`. OpenAI and open_responses package trees were unchanged at `e47e4eb91517028ab73172d3bd219cbd1ab48a6b`. Anthropic files involved in the shared transport and Managed Agents findings were unchanged at that commit. The later Message Thread and signed compaction additions require integrated review on the final alignment head. The OpenAI package owns its public Responses implementation. The open_responses probe serves as a limited sibling implementation comparison for terminal mapping and diagnostics.

Existing focused Anthropic cancellation and error suites passed 102 tests. Existing OpenAI cancellation, abort and error suites passed 39 tests. The additional probes exercised failures with mocked credentials and response bodies, including invalid UTF-8 bytes and stalled body streams.

The first [#498](https://github.com/davidmigloz/ai_clients_dart/issues/498) fix adds deterministic tests in `test/unit/resources/http_error_response_test.dart` and `test/unit/client/retry_after_test.dart` for the shared Anthropic HTTP failure and retry paths.

## Sibling comparison

The representative open_responses SSE implementation closes the typed stream and cancels the stalled body once on a malformed known event, while leaving the borrowed transport open. Its unknown response event preserves the nested payload. Its own buffered diagnostics retain the server header for valid errors, but malformed body bytes mask the exception and oversized 429 Retry-After overflows. Its SSE valid 503 loses server response metadata, 429 loses retry guidance, and malformed 503 bytes surface FormatException. These observations apply to the separate open_responses package. The OpenAI public Responses resource uses its own transport.
