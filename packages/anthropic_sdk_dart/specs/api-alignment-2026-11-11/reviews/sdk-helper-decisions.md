# Official SDK helper decisions

This audit uses the November 11, 2026 cutoff, Python v2.8.0 at `5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9` and TypeScript sdk-v1.8.0 at `590783078cd961a0df698d9fddc0275c65ff3afd`. The operation and schema inventory covers the public HTTP contract. The entries below describe the Dart behavior for helpers that sit above it.

## Implemented workflows

| Workflow | Dart behavior and source decision |
| --- | --- |
| Static environment credentials | The explicit environment factories select API key, then OAuth token. Dart retains the value as supplied, as Python does. TypeScript trims it. The established Dart bearer provider supplies its OAuth beta. The pinned SDK static paths set Bearer directly. Effective header values are checked before transport. [Python environment precedence](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/_client.py#L98-L112) · [TypeScript environment reader](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/internal/utils/env.ts) |
| Cursor pagination | `CursorPagination` lazily exposes typed pages or items through Dart streams. The caller supplies the endpoint's continuation rule, preserving ID, token and opaque cursor families. Tests cover continuation, filters, errors, pause, cancellation and early exit. [Python pagination](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/_base_client.py#L244-L412) · [TypeScript pagination](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/core/pagination.ts#L154-L470) |
| Messages response metadata | `createWithResponse()` returns the same decoded `Message`, HTTP status, and available safe Claude, workspace, AWS and Azure identifiers in one request. Python and TypeScript attach Claude IDs to decoded objects and expose broader raw response access. Dart keeps message serialization and equality focused on the response body. [Python model metadata](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/_models.py#L193-L217) · [TypeScript metadata parser](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/internal/parse.ts#L73-L93) |
| Structured output | `parse()` and `parseStream()` use an explicit JSON Schema and typed Dart decoder. Completed natural turns and requested stop sequences decode typed output. Other stop reasons retain the raw response for recovery. Pydantic and Zod derive schemas from their language-specific runtime types. [Claude structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs) · [Python parser](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/lib/_parse/_response.py) · [TypeScript parser](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/lib/parser.ts) |
| Messages tool runs | `runTools()` provides typed callbacks, buffered or SSE turns, a cap, cancellation, and opt-in beta threads or a stateless signed summary. Expired continuations reach callers. Browser and computer adapters gate sensitive actions and pair results. Applications provide the executors and platform policies. The runner retains full history when a signed summary loses tool changes. [Python tool runner](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/lib/tools/_beta_runner.py) · [TypeScript tool runner](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/lib/tools/BetaToolRunner.ts) |
| Cloud routing and credentials | The provider adapters implement the pinned request, response and auth wire contracts. Applications can connect their existing AWS, Google and Azure identity libraries through credential callbacks. Dart uses explicit `AuthProvider` and WIF exchange with an injected JWT provider for first-party scoped credentials. ## Remaining SDK conveniences

- **Managed Agents execution.** The public session event and work queue APIs support caller-owned executors. An automatic session runner needs event/history reconciliation, idempotent tool result delivery, confirmation and permission handling, bounded reconnects and deterministic cancellation. A native environment worker also needs an isolated filesystem and process runtime, lease renewal and ownership-loss fixtures, and bounded archive handling. [Pinned session runner](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/lib/tools/SessionToolRunner.ts) · [Pinned worker](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/lib/environments/worker.ts)
- **Local MCP adapters and fallback middleware.** Dart exposes server-side MCP and typed result content, plus server fallback and explicit credit reuse. A local MCP adapter needs a caller-owned transport and verified mapping for tool, prompt and resource content. Automatic local refusal fallback needs bounded requests, credit use and SSE splice semantics. [Pinned MCP adapters](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/helpers/beta/mcp.ts) · [Pinned fallback middleware](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/lib/middleware/_fallbacks.py)
- **Generic raw response wrappers and tracing.** Injected HTTP clients can observe raw responses. Dart exposes typed streaming events and binary download APIs. Full per-resource raw wrappers need a stable ownership, retry and cancellation contract. Admin telemetry destinations configure server export. Client-side GenAI spans need an opt-in Dart tracer integration, content-off defaults and tests for retries, stream completion and redaction. [Pinned raw response wrapper](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/_response.py#L649-L809) · [Pinned TypeScript tracing](https://github.com/anthropics/anthropic-sdk-typescript/blob/590783078cd961a0df698d9fddc0275c65ff3afd/src/internal/tracing.ts)
- **Native credential discovery.** Vendor default credential discovery needs compatible Dart identity integrations for the supported platforms. First-party profile discovery and refresh need an explicit filesystem and permission model, token rotation, atomic writes and concurrency tests. The official low-level WIF helpers can omit `service_account_id`; Dart requires the field documented in the public contract. [Pinned credential chain](https://github.com/anthropics/anthropic-sdk-python/blob/5139cf2e7d07aa618a6c30b7e0c712f10ccb5ad9/src/anthropic/lib/credentials/_chain.py) · [WIF request contract](https://platform.claude.com/docs/en/manage-claude/wif-reference#token-exchange-request)

Hosted beta, Enterprise, Compliance and cloud access were verified through pinned contracts and deterministic fixtures. Live service verification requires credentials and entitlement on each applicable platform, plus explicit authorization for live requests.
