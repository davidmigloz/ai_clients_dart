## Proposed release

Recommend **11.0.0** after approval. The new default Claude API version and additions to exported enum and sealed types can require caller changes. Review these migrations before upgrading.

- Remove legacy sampling controls and incompatible cited user input under `2026-10-21`. Move direct assistant documents to user turns. Use `AnthropicConfig.legacyApiVersion` for callers that still need the previous first-party contract. Match Bedrock and Vertex versions to the deployed model.
- Update exhaustive switches for unfamiliar stop reasons, stream events, batch results, and new thinking and Managed Agents variants. Preserve raw response values when replaying or forwarding them. Handle `MessageStreamFailure` when aggregating failed streams.
- Adopt current Files and Skills cursor and response shapes, `output_config.format` for structured output, and the current Messages MCP toolset declarations. Use `client.userProfiles.current` for GA User Profiles. Update Admin API key scope, rate-limit group, and Enterprise Analytics readers for the current envelopes.

[Migration guide and before-and-after examples](../../../MIGRATION.md)

The recorded SDK conveniences include automatic Managed Agents session runners and native environment workers, local MCP adapters and automatic refusal fallback middleware, generic raw-response wrappers and client-side tracing, and native credential discovery. These require dedicated runtime, ownership, or platform integration work. Hosted beta, Enterprise, Compliance, and cloud behavior was checked using pinned sources and deterministic fixtures. Live entitlement checks require the relevant account access and separate authorization for live calls. [Official SDK helper decisions](sdk-helper-decisions.md)

Release approval authorizes the separate version bump, generated changelog, tag, and publication workflow.
