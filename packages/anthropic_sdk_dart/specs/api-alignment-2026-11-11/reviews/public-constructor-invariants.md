# Dart constructor audit

Dart 3.12 exposes the argument for a private named initializing formal without its leading underscore. The visibility of the constructor itself determines whether an external caller can supply that argument. [Dart constructor reference](https://dart.dev/language/constructors)

Anthropic source was archived at `4635874ced952fb2855bd9254f6ecbfca5ae04e2`. The comparison baseline was `acbd8c80ef6550e932319873b1778be2c575a0cd`. Scanned `git grep -n -E 'this\._[A-Za-z_][A-Za-z0-9_]*' <revision> -- packages/anthropic_sdk_dart/lib`, then inspected the enclosing constructor and public export for each named occurrence. Eight public Managed Agents constructors accepted parser-only raw strings or nullable-presence flags. Their typed parameters keep the public signatures. The JSON factory and copy paths retain raw values and explicit nullable fields through a private constructor. `FallbackCreditNotApplied(reason:)` and `FallbackCreditNotApplied.raw(rawReason:)` are intentional alternatives. `ManagedWebFetchUrlSourceFilter.all/none(shorthand:)` intentionally chooses the request wire form.

The sibling scan used `git grep -n -E 'this\._[A-Za-z_][A-Za-z0-9_]*' acbd8c80ef6550e932319873b1778be2c575a0cd -- packages/openai_dart/lib` and the same command against `f6c4d356d303710ad890eb3e36cd59a88cc3920e`. Both returned 85 source lines, and `git diff --numstat` for the sibling library was empty. Raw model-state flags on reasoning details, Responses SSE errors, and chat stream choices/deltas already use private constructors. The public typed instructions, Responses steer content, and AgentSessionRun resource arguments have caller-facing semantics. `ResponsesRecoveringWebSocket` is an internal implementation without a barrel export. `ApiException(misalignment:)` is externally callable and takes typed diagnostic data that overrides the optional parsed body field. A public tear-off fixture reproduced the override. This is a pre-existing exception-construction choice, separate from the Anthropic wire-state issue.

The four focused tests failed against the unmodified Anthropic baseline and passed after the fix. The full package suite passed 2,345 tests with three environment skips on Dart 3.13.7. Static analysis was clean.
